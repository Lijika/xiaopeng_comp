# 任务4 范围决议：官方子集 + 配置预留 + 合成跨单演示

**状态：** 已确认（2026-07-25）  
**ADR：** `docs/adr/0001-task4-data-scope.md`  
**词汇：** `CONTEXT.md`

---

## 1. 决议一句话

> **真数只做官方登记证样本级提取/展示/样本内校验；跨单据能力用配置预留 + 合成数据演示，不假装官方有合同/金额。**

---

## 2. 两条路径

| 路径 | 数据 | 做什么 | 不做什么 |
|------|------|--------|----------|
| **A. 官方真链路** | 登记证影像 + 版面 + 抽取填字 | 样本级字段提取、页/框展示、样本内一致性 | 伪造多业务单据 |
| **B. 合成跨单演示** | fixtures 多单据 JSON | 展示跨单据规则、三态报告、规则/别名配置 | 写入「官方指标」 |

---

## 3. 官方真链路：字段与页（当前可依赖）

### 页

- **注册页**：大框 class_id **4/5/6**；编号 **8**；细字段 11–17、9 等  
- **登记页**：登记栏 **7**；编号 **10**（语义 ≈ 注册页 **8**）

### 优先提取/展示字段（有 OCR/识别后）

| 字段 | 主要来源 class_id | 样本内校验示例 |
|------|-------------------|----------------|
| 登记证编号 | 8（注册页）、10（登记页） | 8 与 10 一致/存疑 |
| VIN | 14 | 多页重复出现时一致 |
| 发动机号 | 15 | 同上 |
| 品牌/型号/类型 | 12/13/11 | 展示 + 可选一致 |
| 燃料/制造厂 | 16/17 | 展示 |
| 姓名/地址/日期 | 大框 4/5/6 内或细框（需识别） | 有字再校验 |

### 明确不做真数的

- 融资金额、发票金额、合同条款金额  
- 保单/合同/发票/身份证整单（除非赛题方另给并走配置接入）

---

## 4. 配置预留（给赛题方）

系统须保持可配置：

- 单据类型列表（`doc_type`）  
- 字段别名（如 owner_name ↔ lessee_name）  
- 规则类型：exact / fuzzy / numeric_tolerance / list_contains / conditional_required  
- 规则维护界面 / YAML（已有）  
- 输入契约：Application JSON（多 documents）

赛题方有私有多单据时：灌入结构化 JSON + 调规则即可，无需改引擎内核。

---

## 5. 合成演示（展示跨单）

- 继续使用 `fixtures/applications/*` 多单据样例  
- 标记 `meta.field_source = synthetic`  
- Web 场景可同时提供：  
  - 「官方样本（登记证）」  
  - 「合成跨单演示」  
- 评估：`evaluate --suite main` 可含合成标签集，但报告必须写清数据性质

---

## 6. 实现优先级（据此排期）

1. 样本级：登记证版面（页/框）+ 展示  
2. 填字：抽取结果写入字段  
3. 样本内校验：尤其登记证编号跨页一致  
4. 合成跨单演示与配置说明保持可用（已有基础）
