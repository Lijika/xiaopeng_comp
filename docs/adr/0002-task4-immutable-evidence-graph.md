# ADR-0002: 任务4跨单据核验使用不可变证据图

## Status

Accepted - 2026-08-01

任务四以申请内的不可变证据图而非可覆写的单据字段模型表示跨单据核验：原始附件/页与单据实例分离，字段观察只追加，校验运行固定字段证据快照，规范实体与校验发现只保留可追溯关联。这样可诚实表达同类型多单据、多候选、页重归属和人工修正；单一 `Document.fields` 模型不能保留这些历史及其对当前核验运行的失效影响。

## Considered Options

- 单据实例上每个字段只保留一个当前值：实现简单，但会丢失候选、来源、修正历史和歧义。
- 不可变证据图：保留完整审计链和运行快照，代价是需要显式归属、选用和失效关系。
