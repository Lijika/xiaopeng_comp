# ADR-0003: 任务4区分公开演示与受控数据处理边界

## Status

Accepted - 2026-08-01

一致性审核工作台会处理可识别个人、车辆和申请的原始附件与字段证据，而现有可选共享令牌、原值直出、本地文件持久化和尽力审计只能支撑竞赛演示。任务4因此将公开的**竞赛演示环境**与处理真实数据的**受控部署环境**定义为不同信任边界：前者只接收合成或不可逆匿名化数据；后者采用机构控制的单租户隔离、机构身份认证、按角色和资源范围默认拒绝、后端数据最小化、保留期内只追加与到期合规删除、受控导出、独立安全审计及网络出口默认拒绝。身份、授权、分类、脱敏、密钥、完整性或必要审计无法确认时失败关闭；外部依赖不可用时显式转人工复核或暂不可处理，不降级绕过控制。

详细角色矩阵、数据分级和操作政策由[确定安全、隐私、角色权限与部署约束](https://github.com/Lijika/xiaopeng_comp/issues/5)的 resolution 持有。后续架构和实施可以选择具体身份源、基础设施与存储技术，但不得把演示能力表述为受控部署基线，也不得削弱上述边界。

## Considered Options

- 以共享令牌和网络位置保护同一套演示部署：改造少，但无法识别操作者、实施职责分离或证明受限数据访问可问责。
- 区分演示与受控部署边界：增加身份、隔离、持久化和运维成本，但使公开展示与真实数据处理的风险和证据声明保持诚实。
